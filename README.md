# DataScience-Bootcamp2026

- `solution.ipynb` — решение с пояснениями, обучением и проверкой качества.
- `datasets/` — три исходных Parquet-файла.
- `answer.csv` — проверенный файл для отправки: 2 452 запроса, по 50 объявлений.

Для воспроизведения откройте ноутбук в Jupyter или Colab (Python 3.12)
и выполните все ячейки сверху вниз. Зависимости указаны в первой ячейке;
Python-скрипты и заранее сохранённая модель не нужны.
Ноутбук заново создаст `answer.csv`, а вспомогательные артефакты сохранит
в `notebook_outputs/`.

CSV проверен по требованиям задания и побайтово совпадает с результатом
полного запуска самостоятельного ноутбука.
